# ADR-001: Alcance Exclusivo para Qwen3-TTS `0.6B`

- **Estado**: Aceptado
- **Fecha**: 2026-11-16

## Contexto
El motor C original (`qwen3-tts/`) soporta tanto `0.6B` como `1.7B` (`CustomVoice`, `Base` y `VoiceDesign`), lo que introduce polimorfismo dinámico de dimensiones (`1024` vs `2048`), la proyección `small_to_mtp_projection` (`cp_mtp_proj`), y todo el subsistema de emociones del `1.7B` (`--instruct`, `--voice-design`, `.qlsteer`, `.expr`, `resolve_emotion_recipe`). El proyecto objetivo solo requiere ejecutar `Qwen3-TTS 0.6B`.

## Decisión
Dedicar el nuevo motor Rust **exclusivamente a `Qwen3-TTS 0.6B`** (`CustomVoice` y `Base`), fijando su geometría (`H=1024`, `INTER=3072`, `HEAD_DIM=128`, `28` capas Talker, `5` capas CP) y podando todas las rutas exclusivas de `1.7B`.

## Consecuencias
- **Positivas**:
  - Elimina ~30–40 % de complejidad accidental (`cp_mtp_proj`, `ml_steer`, `.expr`, `voice_design`, `instruct`).
  - Permite que LLVM optimice bucles sobre tamaños constantes conocidos en compilación.
  - Simplifica el perfil `--quant-mixed` como ruta principal de producción.
- **Negativas / Mitigación**:
  - Si en el futuro se requiriera `1.7B`, la carga actual lo rechazará explícitamente al validar `config.json` (`hidden_size == 1024`). Como `Model06B`, `VoiceBindings` y `SessionScratch` ya están desacoplados, añadir otro tamaño en el futuro seguiría siendo acotado y limpio.
