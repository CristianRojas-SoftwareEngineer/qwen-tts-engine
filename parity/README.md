# Parity Harness (C vs Rust)

Directorio destinado a la línea base del motor C (`qwen3-tts/`) y a las pruebas comparativas A/B frente a `qwen3-tts-rs/`.

- `golden/` — Referencias pequeñas versionables (métricas, hashes, salidas de `--self-test` y dumps de códigos de prueba).
- `runs/` — Salidas temporales WAV/PCM/logs (ignorado en Git).
